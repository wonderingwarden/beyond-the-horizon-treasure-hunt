# Security and privacy

This is a static, client-side project. It does not use a backend, collect form submissions, or require secrets.

## Reporting an issue

Please report a security or privacy concern privately to the repository owner before opening a public issue if the report could expose sensitive information.

## Public-release checklist

- Confirm all collaborators have approved public release.
- Confirm the map images, clue text, fonts, and other included material can be published.
- Do not add API keys, passwords, access tokens, or personal information to the repository.
- Recheck external links and dependencies before adding them.
